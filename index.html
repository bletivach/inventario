📱 Como usar no telemóvel e computador

Esta app guarda os dados no browser (localStorage). Para sincronizar entre dispositivos, usa o sistema de exportação/importação:

  1. No computador, clica ⬇ Exportar dados — descarrega um ficheiro .json
  2. Envia esse ficheiro para o telemóvel (WhatsApp, email, Google Drive...)
  3. No telemóvel, abre a app e clica ⬆ Importar dados
  4. Seleciona o ficheiro .json — os dados ficam sincronizados!

🌐 Como hospedar online (acesso por URL)

Para aceder à app por um link sem precisar de ficheiros:

  1. Vai a github.com e cria uma conta gratuita
  2. Cria um repositório chamado inventario-valedoave
  3. Faz upload deste ficheiro HTML com o nome index.html
  4. Vai a Settings → Pages → Source: main branch
  5. A app fica disponível em: https://[teu-utilizador].github.io/inventario-valedoave

⚠️ Mesmo online, cada browser guarda os seus próprios dados. Para sincronizar tens sempre de exportar/importar.

💡 Dica: Adicionar ao ecrã principal do telemóvel

  1. Abre a app no browser do telemóvel (Chrome ou Safari)
  2. Clica nas opções do browser (⋮ ou ⊞)
  3. Escolhe "Adicionar ao ecrã principal" ou "Instalar app"
  4. A app aparece como ícone no telemóvel, como uma app normal!
